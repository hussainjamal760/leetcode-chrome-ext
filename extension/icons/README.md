# Extension Icons

Place your extension icons in this directory:

- `icon16.png` - 16x16 pixels
- `icon48.png` - 48x48 pixels  
- `icon128.png` - 128x128 pixels

## Creating Icons

You can create icons using:
1. Online tools like Canva or Figma
2. Image editors like Photoshop or GIMP
3. Icon generators

## Recommended Design

- Use a simple, recognizable symbol (e.g., GitHub logo + LeetCode colors)
- Ensure good contrast for visibility
- Keep it simple and clean
- Use PNG format with transparency

## Quick Solution

For testing, you can use a simple colored square or download free icons from:
- https://www.flaticon.com/
- https://icons8.com/
- https://www.iconfinder.com/

Just make sure to follow their licensing terms.
